ReferenceSystems.jl

ReferenceSystems.jl provides lightweight abstractions for astronomical time systems, Earth orientation, coordinate systems, and reference-frame transformations.

Package structure

The package currently contains:

  • TimeSystems — epochs and time-scale conversions
  • EarthOrientation — Earth-orientation parameters such as DUT1
